# A03 · שכחתי סיסמה ואיפוס

**מפתחת:** C-02 (שני המסכים שלה: A03 ו-N03) · **מורכבות:** בינוני · **מודול:** כניסה והחשבון שלי
**צוות:** C · נוכחות, צוות וחשבון (Jira 3)

## מטרה

שני שלבים: בקשת קישור איפוס במייל, והגדרת סיסמה חדשה מתוך הקישור.

**מי משתמש:** כל המשתמשים
**איך מגיעים:** קישור 'שכחתי סיסמה' במסך ההתחברות.

## מה נבנה בגרסה 1 (v1-lite)

**נכלל:** בקשת איפוס והגדרת סיסמה חדשה; תוכן המייל נרשם ללוג בלבד.
**נדחה:** שליחת מייל אמיתית.

כשיש סתירה בין המפרט המלא להיקף v1-lite, v1-lite קובע.

## אזורי המסך

- **שלבים** (steps): בקשת קישור · בדיקת מייל · סיסמה חדשה · הושלם
- **שלב 1: בקשה** (form): אימייל *
- **שלב 3: סיסמה חדשה** (form): סיסמה חדשה * עם מד חוזק · אימות סיסמה *
- **פעולות** (actions): שלח קישור · שמור סיסמה · חזרה להתחברות

## פעולות ותגובות

- הודעת ההצלחה בשלב 1 זהה גם כשהמייל לא קיים.
- שמירת הסיסמה מנתקת את כל המכשירים האחרים.

## כללים ותנאים

- הטוקן חד-פעמי ותקף לזמן קצר.
- אין חשיפה האם כתובת מייל רשומה.
- מייל האיפוס נשלח בשירות מדומה בגרסה 1.

## מצבי המסך

טעינה, ריק, שגיאה ואין הרשאה לפי מסך המצבים המשותף (X02).

## API

- `POST /auth/reset`
  החוזה המלא ב-`openapi/openapi.yaml`.
